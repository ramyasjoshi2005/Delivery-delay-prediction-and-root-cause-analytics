Delivery Delay Prediction & Root-Cause Analytics

Amazon Data Scientist-1 Intern Project

1. Overview

Business Problem: Late deliveries impact customer satisfaction. Can we predict if an order will be late using only pre-delivery data?

Target: Late = 1 if Actual Delivery Date > Promised Delivery Date.

Leakage Prevention: Removed all post-order metrics (e.g., actual delivery date, delivery status) from features to prevent data leakage.

2. Statistical Analysis

Research Question: Is the late-delivery rate significantly different between Standard Class and First Class shipping?

Null Hypothesis: No difference in late-delivery rate.

Alternative Hypothesis: Significant difference in late-delivery rate.

Test: Two-Proportion Z-Test

  • Group 1 (Standard Class) Rate: 39.77%
  • Group 2 (First Class) Rate: 100.00%
  • Z-statistic: -179.27
  • p-value: 0.0 (Reject Null Hypothesis)

Interpretation: Standard Class has a significantly lower late-delivery rate compared to First Class.

3. Model Performance

Selected Model: Random Forest (Selected based on PR-AUC & F1)

Threshold Analysis: Selected 0.4 to balance Precision and Recall.

  • ROC-AUC: 0.7457
  • PR-AUC: 0.8430
  • Precision: 0.8293
  • Recall: 0.6003
  • F1: 0.6965

4. Root-Cause Analytics (SHAP)

According to our SHAP explainer, the most critical factors for delay prediction are:

  1. Shipping Mode (Standard Class vs. First Class)
  2. Promised Delivery Days (Scheduled Days)
  3. Sales & Order Timing (Month/Day of week)
